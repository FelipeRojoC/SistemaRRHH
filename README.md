# Catedra-2

Este sistema permite gestionar el arriendo de vehiculos y el registro de sus mantenimientos tecnicos.

Consta de dos modulos principales: uno dedicado a la operacion comercial de renta y otro encargado del control de la flota y el taller. Ambos modulos se comunican para mantener actualizados los estados de disponibilidad de los vehiculos en tiempo real.

Autores: Bruce Munizaga, Felipe Rojo, David Alvarez.
